Quick Start Guide

Get Caddie running inside your CAD software in under 5 minutes.

Alpha release — Caddie is under active development. SolidWorks 2022+ is fully supported today. Fusion 360 and Onshape integrations are on the roadmap.

System Requirements

  • Operating System: Windows 10 or Windows 11 (64-bit only)
  • CAD Software: SolidWorks 2022 or later
  • .NET Framework: 4.8 — already installed on most Windows 10/11 machines
  • Internet: Required for AI responses (requests go through a secure HTTPS relay — see Privacy)
  • Disk space: ~20 MB installed, plus space for local conversation history

Step 1 — Download & Install

  1. Download CaddieSetup.exe from the download section.
  2. Run CaddieSetup.exe.
    ⚠ Windows SmartScreen may show a warning because the installer is not yet code-signed. Click More info → Run anyway. This is normal for indie software during alpha.
  3. Click through the setup wizard. The default install location (C:\Program Files\Caddie\) is recommended.
  4. If SolidWorks is running, the installer will ask you to close it first — this is required so the DLL can be written.
  5. Click Finish. Caddie is now installed and registered.

Step 2 — Enable in SolidWorks

  1. Open SolidWorks (or restart it if it was already running).
  2. Go to Tools → Add-Ins…
  3. Find Caddie in the list of available add-ins.
  4. Check the Active checkbox to load it now, and check Start Up so it loads automatically every time SolidWorks opens.
  5. Click OK.
  6. The Ask Caddie panel will appear on the right side of your SolidWorks window.

Step 3 — Start Working Together

  1. The first time Caddie opens, it explains what it sends to answer you. Read it and click Got it.
  2. Open any part, assembly, or drawing. Caddie follows what you do as you work, and the badge at the top shows any problems it spots.
  3. Tell Caddie what you need in your own words and press Enter. To stop a reply, click the stop button or just type something else.
  4. When Caddie can make a change for you, it shows a card. Nothing changes until you click Do it, and most changes have an Undo.
  5. If you'd rather do it yourself, ask it to walk you through. A highlight points at each thing to click, and each step ticks itself off as you finish it.
💡 Things to try
"this sketch is red, fix it"  •  "round the four corners, 5 mm"  •  "six of these holes around the centre bore"  •  "walk me through a chamfer, I want to learn it"  •  "undo that"
Set Settings → How you work to your own standards, such as units, drawing standard and default material, and Caddie follows them in every answer.

What leaves your computer

To answer you, Caddie sends your question, your model's details and a screenshot of SolidWorks to OpenAI, with storage turned off. Your files are never uploaded, your history stays on your PC, and you can turn screenshots off in Settings. Full privacy details.

Updating Caddie

When a new version is released, Caddie will show an update banner inside SolidWorks automatically. Updating takes about 30 seconds:

  1. Click the Download link in the update banner, or visit the download page.
  2. Run the new CaddieSetup.exe — it detects your existing installation and upgrades automatically.
  3. Reopen SolidWorks. The updated version loads automatically.

Uninstalling

  1. Close SolidWorks.
  2. Open Windows Settings → Apps (or Control Panel → Programs).
  3. Find Caddie for SOLIDWORKS in the list and click Uninstall.
  4. Optionally delete the app data folder to remove conversation history and settings: %AppData%\CaddieAddin\

Troubleshooting

The add-in doesn't appear in Tools → Add-Ins
Close SolidWorks and run CaddieSetup.exe again, approving the administrator prompt. Then reopen SolidWorks, go to Tools → Add-Ins and tick Caddie under both Active and Start Up.
Caddie says it has run out of credit, or can't sign in
The AI service behind Caddie needs attention from whoever set Caddie up. Nothing is wrong on your PC. If it says it can't sign in, installing the latest version usually fixes it.
Caddie loads but can't connect to AI
Check your internet connection. Caddie routes AI requests through a secure HTTPS proxy — make sure your firewall or corporate network isn't blocking outbound connections to *.workers.dev. If you're on a VPN, try disabling it temporarily to test.
The taskpane is blank or stuck on "Loading…"
Caddie's panel needs the Microsoft Edge WebView2 Runtime, which the installer adds when it's missing. Run CaddieSetup.exe again, or install the runtime from Microsoft, then restart SolidWorks.
Caddie doesn't seem to see my latest change
Caddie follows your work as you go and re-reads the model before every answer. If something still looks stale, click ↻ Refresh at the top of the chat.
SolidWorks shows "Add-in failed to load" on startup
Run CaddieSetup.exe again to repair the installation. If you recently updated Windows, also repair .NET Framework 4.8 through Windows Update.
Reporting a problem
In Caddie, go to Settings → Copy a problem report and paste it into an email. It contains Caddie's version, a recent log and any answers you've rated, and you can read it before you send it.
Still stuck? Email hello@askcaddie.app — we respond quickly during the alpha.
